# PDF Merge
Programa para mesclar .pdf

crie uma pasta e adicione o arquivo "Juntar.py" e crie mais uma pasta chamada "arquivos" dentro dela.
Coloque os .pdf que queira juntar na pasta "arquivos"  de run no arquivo "juntar.py".
Se quiser ordenar os pdfs, renomeie os arquivos pela ordem que você quer que apareçam no PDF Mesclado. EX: 01.pdf, 02.pdf
Isso vai gerar um PDF final, que seria a mescla de todos os arquivos.
